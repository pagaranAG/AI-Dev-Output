## Overview

Sisig House is a fictional premium Filipino restaurant chain founded in 2015 by Maria Santos in Calamba, Laguna. What began as a small food cart has grown into a beloved chain with 6 locations across Laguna Province. This website serves as the official online presence for the restaurant, offering visitors a full look at the menu, branch locations, and the story behind the brand.

## 🤖 AI Vibe Coding with GitHub Copilot

This project was built as a **hands-on test of GitHub Copilot's AI vibe coding power** — a development style where you describe what you want in natural language and let AI generate the code, structure, and content for you.

### What was tested:
- ✅ Generating a complete multi-page HTML/CSS website from prompts
- ✅ Creating realistic Filipino restaurant content (menu items, prices, branch details)
- ✅ Structuring consistent navigation and layout across 4 pages
- ✅ Embedding interactive Google Maps without manual coding
- ✅ Designing responsive UI components with minimal manual intervention

### Verdict:
GitHub Copilot demonstrated strong AI vibe coding chops — producing coherent, styled, and content-rich pages that required little to no hand-written code. A great showcase of how AI can accelerate front-end development even for domain-specific projects like a local restaurant website.

## Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/pagaranag/AI-Dev-Output.git

# Navigate into the project folder
cd AI-Dev-Output

# Open in your browser
open index.html
```

No build tools or dependencies required — it's a plain static website.
